# ⚡ TRACE ERP — CS Quick Tagging Chrome Extension

This Chrome Extension injects a **1-Click Tagging Assistant Bar** directly into Shopify Admin Order Pages, connected in real-time with **TRACE ERP**.

---

### 🚀 2-Minute Installation Guide for CS Team:

1. **Chrome Extensions Page Open Karein**:
   * Chrome browser me URL type karein: `chrome://extensions/`
   * Top-Right corner me **Developer mode** toggle ON karein.

2. **Extension Load Karein**:
   * Top-Left button **"Load unpacked"** par click karein.
   * Project folder me se `shopify-cs-tagger-extension` folder select karein.
   * Done! Extension active ho jayegi! 🎉

---

### 🎯 Predefined Tags Included:

* 🟢 **WhatsApp** (`Alt + W`)
* 🟣 **WhatsApp-In-Funnel** (`Alt + F`)
* 🔵 **Prepaid** (`Alt + P`)
* 🟡 **Claim** (`Alt + C`)
* 🔴 **Cancel Request** (`Alt + X`)
* 💗 **Address Change** (`Alt + A`)
* ⏸️ **Hold / Pending** (`Alt + H`)
* 🔄 **Exchange** (`Alt + E`)
